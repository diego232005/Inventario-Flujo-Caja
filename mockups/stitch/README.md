# Mockups (exportación estilo Google Stitch)

Estas vistas HTML representan el diseño aprobado para el MVP. En un flujo con Stitch se exportarían desde la herramienta; aquí se conservan como prototipos visuales alineados a `PRD.md` y `design.md`.

## Vistas
| Archivo | Vista |
|---------|-------|
| `01-dashboard.html` | Tablero de cierre mensual |
| `02-inventario.html` | Catálogo / inventario |
| `03-proveedores.html` | Gestión de proveedores |
| `04-ordenes-sugeridas.html` | Órdenes de compra sugeridas |

Abrir los HTML en el navegador para revisión visual. El frontend React implementa el mismo layout y tokens.
